## ResumeIQ Design and Frontend Development Policy

The project owner has selected the following design guidance:

https://github.com/elayadesign/ai-design-skills

### Mandatory design requirements

- Use `elayadesign/ai-design-skills` as the primary UI/UX design reference.
- Better Design MCP is optional and is NOT required.
- Do not block frontend implementation because Better Design MCP is unavailable.
- Redesign the entire ResumeIQ application with a distinctive, premium, professional SaaS design.
- Use consistent typography, spacing, layout, color tokens, motion, and components.
- Support responsive layouts, accessibility, and reduced-motion preferences.
- Preserve existing backend functionality, authentication, resume analysis, and document management.
- Verify frontend builds, functionality, accessibility, and visual consistency.

### Milestone execution

After completing and verifying each milestone:

1. Review changes and check for secrets.
2. Commit the milestone.
3. Push to `feat/resumeiq-saas-transformation`.
4. Verify the remote commit.
5. Continue automatically with the next milestone.

Do not request routine approval between milestones.

Do not merge into `main` or push unverified work.

All other existing repository engineering and security requirements remain unchanged.
